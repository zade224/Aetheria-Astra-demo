# Aetheria Astra — Battle Prototype

A mobile-first landscape turn-based battle test featuring Ayan and the Shadow Beast.

## Run locally
1. Install Node.js 22 or later.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local Vite URL in a browser.
5. Use Normal Attack, Gale Piercer, and Tempest Awakening.

## Prototype notes
- Ayan uses extracted PNG frames in `public/assets/ayan/`.
- Shadow Beast uses a transparent cutout image and CSS state animation.
- Battle math and enemy behavior are prototype implementations, not final balance.
- The starter main menu is replaced by a battle test screen in this package.
